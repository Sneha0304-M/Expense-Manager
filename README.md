# Expense-Manager

## About the Project

Expense Manager is a personal finance management application built using Java and Spring Boot. The project is designed to help users manage and track their expenses.

**Project Status:** Work in Progress

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven

## Project Structure

The application follows a layered architecture:

- **Controller:** Handles incoming application requests.
- **Service:** Contains the business logic.
- **Repository:** Handles database operations.
- **Model:** Represents the application's data.
- **Exception Handling:** Manages application errors and exceptions.

## Current Progress

The project includes the initial Spring Boot application structure, expense-related classes, repository and service layers, and exception-handling components.

Some features are still under development, and the application may require further debugging and testing.

## Learning Objectives

- Practise Java backend development.
- Understand Spring Boot application structure.
- Learn layered architecture and separation of concerns.
- Practise database integration using Spring Data JPA and Hibernate.

## Future Improvements

- Complete and test expense CRUD operations.
- Improve input validation and exception handling.
- Test database integration.
- Add a frontend for managing expenses.
- Improve documentation and application testing.
